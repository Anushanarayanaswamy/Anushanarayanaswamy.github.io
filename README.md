## 📌 How to Push to GitHub & Enable GitHub Pages

Follow these simple commands to push this project to your GitHub account (`Anushanarayanaswamy`):

### Step 1: Create a new repository on GitHub
1. Go to [GitHub - Create New Repository](https://github.com/new).
2. Set **Repository name**: `portfolio` (or `Anushanarayanaswamy.github.io` for your main profile site).
3. Keep it **Public**.
4. Leave "Add a README file" unchecked (since we already have one ready!).
5. Click **Create repository**.

### Step 2: Push your code from your terminal
Run the following commands in PowerShell/Terminal inside `C:\Users\Anusha\.gemini\antigravity-ide\scratch\anusha-portfolio`:

```bash
git remote add origin https://github.com/Anushanarayanaswamy/portfolio.git
git branch -M main
git push -u origin main
```

### Step 3: Enable Free GitHub Pages Deployment
1. Go to your repository on GitHub: `https://github.com/Anushanarayanaswamy/portfolio/settings/pages`
2. Under **Build and deployment** -> **Source**, select **Deploy from a branch**.
3. Choose Branch: `main` / Folder: `/ (root)`.
4. Click **Save**.

🎉 Your portfolio will be live at: **`https://Anushanarayanaswamy.github.io/portfolio`**!
